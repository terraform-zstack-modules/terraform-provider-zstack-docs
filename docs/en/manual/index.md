# User Manual

The user manual explains the customer-facing workflows for ZStack provider
`1.1.3`. It is not a copy of the provider reference. It focuses on how to use
resources safely in real delivery scenarios.

Recommended reading order:

1. Getting started and authentication.
2. Query existing resources with data sources.
3. Create a VM and attach networking, security group, volume, and image inputs.
4. Add production scenarios such as EIP, load balancer, VPC, scripts, IAM, and
   monitoring.
5. Use import and migration guidance before bringing existing resources under
   Terraform management.
